Screen Pet 로컬 테스트 하네스

실제 pets.js / content.js / styles.css 를 그대로 로드합니다. chrome.storage.local 은 localStorage 로 대체돼 탭 간 동기화까지 동작합니다.

  1. 방석 이동 — 우측 하단 방석을 좌우로 끌어보세요. 놓는 순간 stored cushionX 가 갱신되고, 새로고침해도 그 자리에 있어야 합니다.
  2. 클릭 토글 유지 — 방석을 움직이지 않고 짧게 클릭하면 펫이 방석 위로 올라가 자야 합니다 (atHome=true). 다시 클릭하면 내려옵니다.
  3. 펫을 태운 채 이동 — 재운 상태에서 방석을 끌면 펫이 방석에 붙어 따라와야 합니다.
  4. 경계 clamp — 방석을 화면 왼쪽/오른쪽 끝 밖으로 끌어도 화면 안에 붙어야 합니다.
  5. 창 크기 보존 — 방석을 오른쪽 끝에 두고 창을 좁혔다 다시 넓히면, 좁혔을 때는 clamp 되고 넓히면 원래 자리로 돌아와야 합니다.
  6. 배회 범위 — 방석을 왼쪽 끝으로 옮기고 잠시 두세요. 펫이 왼쪽 구석에 갇히지 않고 화면 전체를 돌아다녀야 합니다 (이번에 같이 고친 부분).
  7. 탭 간 동기화 — 이 페이지를 두 탭에 띄우고 한쪽에서 방석을 옮긴 뒤, 다른 탭을 클릭해 포커스를 주면 같은 위치로 따라와야 합니다.
  8. 개발자도구 — ⌥⌘I 로 devtools 를 도킹된 상태로 여세요. 펫과 방석이 즉시 사라지고 rAF running 이 no 로 바뀌어야 합니다. 닫으면 되살아납니다. (별도 창으로 띄우면 감지되지 않는 것이 정상입니다.)

아래로 스크롤해도 펫은 position: fixed 라 화면에 붙어 있어야 합니다.
